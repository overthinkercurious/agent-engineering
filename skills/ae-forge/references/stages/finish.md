# Finish

Dispatch Judge in a fresh context to inspect the approved intent, definition,
plan, integrated diff, command receipts, journey evidence, domain audits,
finding dispositions, configuration changes, and residual risks.

Judge writes `reviews/release-audit.md` and recommends `ready`, `repair`, or
`blocked`. A ready recommendation still requires the runner's deterministic
artifact and approval checks.

Create `final-report.md` with delivered behavior, candidate revision, evidence
per acceptance criterion, specialist participation and cost, residual risks,
rollback or recovery, and the external action remaining. For the MVP, prepare
or create a reviewed pull request according to current authorization.

Before completion, propose durable knowledge discovered during the run. Promote
it only through the owning ae-init artifact process or an ordinary reviewed
project documentation change. Never copy transient reasoning, secrets, or
unverified assumptions into committed project memory.
