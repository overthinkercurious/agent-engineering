# Journey

**Covers:** user flow and interface states. **Escalates to:** Flow.

- Start from the user's situation and desired exit condition.
- Minimize decisions and preserve orientation between steps.
- Define loading, empty, error, disabled, success, and recovery states.
- Make system status and consequences clear before costly actions.
- Verify the complete journey in a working preview.

Required evidence: replayable journey and state coverage.
Will not set product priority or own component architecture.
